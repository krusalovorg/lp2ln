# Third-party licenses

LP2LN uses third-party open-source dependencies from the Rust ecosystem and,
where applicable, frontend dependencies for developer tooling.

Each dependency is licensed by its respective authors.

Before using LP2LN commercially, review dependency licenses with:

```bash
cargo install cargo-deny
cargo deny check licenses
```

For frontend dependencies in `debug-ui`, review package metadata with the
package manager used by that workspace.
